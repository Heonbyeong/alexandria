# 비선형 자료구조

## Tree(트리)

> 노드와 이를 연결하는 간선으로 구성되어, 데이터를 계층적으로 저장하는 자료구조

**특징**

- 부모-자식 관계의 계층적 구조를 가짐
- 모든 노드는 서로 연결되어 있음
- N개의 노드를 가진 트리는 항상 N-1개의 간선을 가짐

**장점**

- 계층 관계를 자연스럽게 표현할 수 있음
- 노드를 쉽게 추가/삭제 할 수 있어 확장성이 높음

**단점**

- 높은 구현 난이도
- 자식 노드 참조를 위해 추가적인 메모리가 필요함
- 트리 균형이 깨지는 경우 성능 저하가 발생할 수 있음

**트리 구성 요소**

![투리 구성 요소](https://github.com/user-attachments/assets/7e835cd4-a002-460f-8ad5-c2b09b1d1310)

| **노드 (Node)** | 트리의 기본 구성 요소, 데이터를 저장하는 단위 |
| --- | --- |
| **루트 노드 (Root Node)** | 트리의 최상위 노드, 부모가 없는 유일한 노드 |
| **부모 노드 (Parent Node)** | 다른 노드에 직접 연결된 상위 노드, 자식을 가지는 노드 |
| **자식 노드 (Child Node)** | 부모 노드로부터 직접 연결된 하위 노드 |
| **리프 노드 (Leaf Node)** | 자식 노드가 없는 노드 |
| **형제 노드 (Sibling Node)** | 같은 부모 노드를 가지는 노드 |
| **외부 노드 (External Node)** | 자식 노드가 없는 노드 (맥락에 따라 리프와 같거나, 리프 밑의 null을 의미) |
| **내부 노드 (Internal Node)** | 자식 노드를 하나 이상 가진 노드 |
| **서브 트리 (Sub Tree)** | 트리에서 부모 노드와 그 자식 노드를 포함하는 트리 |
| **간선 (Edge)** | 노드와 노드를 연결하는 선, 부모와 자식 노드를 연결하는 선을 의미 |
| **노드의 높이 (Height)** | 특정 노드에서 리프 노드까지의 간선 개수 |
| **노드의 깊이 (Depth)** | 루트 노드에서 특정 노드까지의 간선 개수 |
| **레벨 (Level)** | 같은 깊이를 가진 노드들의 집합 |

## Binary Tree(이진 트리)

> 각 노드가 최대 2개의 자식 노드를 가질 수 있는 트리 구조

**특징**

- 각 노드는 데이터, 왼쪽 자식 포인터, 오른쪽 자식 포인터로 구성
- 자식 노드는 명확하게 왼쪽 자식(Left Child)과 오른쪽 자식(Right Child)으로 구분
  
![이진 트리](https://github.com/user-attachments/assets/701c299a-5766-476a-a180-6718b4f1a2f0)

### Full Binary Tree(전 이진 트리)

- 모든 노드가 0(리프 노드)개 혹은 2개의 자식 노드를 가지는 이진 트리
- n0 = n2 + 1 수식을 만족함 (n0은 차수가 0인 노드의 개수)
  
![전 이진 트리 (1)](https://github.com/user-attachments/assets/6b5c851e-ce57-4405-8029-82f2fc56d05c)

### Complete Binary Tree(완전 이진 트리)

- 마지막 레벨을 제외한 모든 레벨이 완전히 채워져 있고, 마지막 레벨의 노드들은 왼쪽부터 차례대로 채워진 이진 트리
- 배열로 메모리 낭비 없이 효율적으로 표현할 수 있음
- 최대힙(Max Heap), 최소힙(Min Heap)의 기반이 되는 구조

![완전 이진 트리 (1)](https://github.com/user-attachments/assets/956fe07f-29a8-4507-8dfd-65714e5ce5ab)

### Perfect Binary Tree(포화 이진 트리)

- 트리의 모든 내부 노드가 2개의 자식을 가지며, 모든 리프 노드가 같은 레벨에 있는 이진 트리
- 리프 노드의 수는 항상 내부 노드 수 + 1을 만족함
- 노드의 수가 2ⁿ-1 인 경우만 포화 이진 트리를 구성할 수 있음

![포화 이진 트리](https://github.com/user-attachments/assets/92a246cd-dfe8-4528-b083-2908756dd065)

### Binary Search Tree(이진 탐색 트리)

- 노드에 대해 왼쪽 서브트리의 모든 노드 값은 현재 노드 값보다 작고, 오른쪽 서브트리의 모든 노드 값은 현재 노드 값보다 큰 이진 트리
- 중위 순회로 노드를 정렬된 순서로 방문하여 탐색의 시간 복잡도는 O(log n)이지만, 최악의 경우 편향 트리가 되어 O(n)이 된다.

![이진 탐색 트리](https://github.com/user-attachments/assets/9b2ded14-fb77-446c-b31a-09b9f3a6059c)

### Balanced Binary Tree(균형 이진 트리)

- 모든 서브트리의 높이 차이가 최대 1인 이진 트리
- 높이 차이가 제한되어 있기 때문에, 최악의 경우에도 검색/삽입/삭제 연산이 O(log n)을 가짐
- AVL 트리, 레드-블랙 트리, B-트리 등이 균형 이진 트리에 속함

![균형 이진 트리](https://github.com/user-attachments/assets/3a462f6f-f846-4d97-9968-20b9e6a9293c)

### Skewed Binary Tree(편향 이진 트리)

- 모든 노드가 한쪽으로만 자식을 가지는 불균형한 이진 트리
- 정렬된 데이터를 순차적으로 삽입하려고 할 때 발생함
- 모든 연산은 O(n)의 시간이 소요

![편향 이진 트리 (1)](https://github.com/user-attachments/assets/ebaa1304-be88-42cd-aedc-9774708ba590)

## Heap(힙)

- 최댓값/최솟값을 빠르게 찾는데 최적화 된 완전 이진 트리 기반 자료구조
- 우선순위 큐와 같은 자료 구조애서 주로 사용
- 삽입 시 값을 마지막 위치에 추가하여 부모 노드와 비교하며 힙 속성을 만족할 때까지 위로 이동(Heapify Up)
- 삭제 시 루트 노드를 제거하여 자식 노드와 비교하며 힙 속성을 만족할 때까지 아래로 이동(Heapify Down)

![힙](https://github.com/user-attachments/assets/aacf9cb0-beda-4edf-add2-39fbd6715ca5)

- **최대 힙(Max Heap)**: 부모 노드의 값이 자식 노드의 값보다 크거나 같음
- **최소 힙(Min Heap)**: 부모 노드의 값이 자식 노드의 값보다 작거나 같음
